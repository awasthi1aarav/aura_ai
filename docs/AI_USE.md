# Use of AI ("SI") tools

As required by the NASA Space Apps rules, this project discloses where AI was used.

- **Code:** AI coding assistants (Claude by Anthropic) helped write and review parts of the backend and
  frontend source code. The team reviewed, tested and adapted it.
- **Product feature:** the AURA Assistant calls the Google Gemini API at runtime to answer crew questions.
  Its answers are AI-generated and labelled in the interface as decision support, not medical diagnosis.
- **Text:** AI tools helped draft parts of the documentation.
- **Images/video:** any AI-generated image, video or voice-over in the demo carries a visible
  "AI-generated" watermark or label. No NASA logos, flags or mission identifiers were generated or modified.
