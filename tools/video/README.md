# Demo video tools

`capture.py` takes 2x screenshots of the live app (start a training scenario in the Demo mission
about 4 minutes before running it). `render.py` turns them into the 30-second captioned 1080p video
(`docs/aura-demo.mp4`). Fonts: Cormorant Garamond and IBM Plex (SIL Open Font License, via Fontsource).
